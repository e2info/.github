## About us

イーツー・インフォは、2005年創業の横浜に本社を置くWebシステム開発会社です。

## Our mission

**ITの力で幸せを形づくる。**

- **お客様と、その先にいる方の幸せ** — お客様の想いを第一に、その先にいるユーザーの顔まで想像して、いちばんフィットする形を提案します
- **仲間の幸せ** — 居心地がよく働きやすい環境こそが良いアウトプットにつながる。一人ひとりが責任を持って自由な働き方を実現します
- **私たちが暮らす街・横浜の幸せ** — 「横浜でIT企業といえばイーツー」と思っていただけるよう、地域に貢献し続けます

## Our stance

私たちが日々大切にしている5つのスタンスです。

- **たのしみ尽くす。** — どんな仕事でも自分なりのたのしみを見つけ、とことんやり切る
- **1ビットでも知識を増やす。** — 学びは持ち運べる財産。シェアして、ITの世界を広げていく
- **誠実にこたえる。** — できること・できないことを明確にし、相手の想いにこたえる
- **自由が自由であり続けるために。** — 一人ひとりがやるべきことをやり、自由な社風を守る
- **半歩先を想像する。** — それが誰の何に役立つのか、自分の範囲のちょっと先を想像する

## What we do

- **ECサイト構築** — 企画・構築・デザインから導入後の保守まで。EC-CUBE のカスタマイズ・バージョンアップも
- **求人サイト構築** — 業種・業態を問わず。PORTERS 連携、SNS・SMS 連携など応募しやすさと運用効率を両立
- **Webシステム / 業務システム開発** — 要件定義・設計・構築・運用保守までワンストップ
- **インフラ** — AWS・Google Cloud の環境構築、移行、コスト最適化
- **運用・保守 / 品質管理 / セキュリティ** — 専任チームによるレビュー・テスト、セキュリティ診断
- **Webデザイン** — コンセプトに基づいた Web / UI デザイン

これまで大手企業から中小企業、自治体・教育機関まで、業種を問わず多くのサイト・システムを手がけてきました。→ [実績紹介](https://www.e2info.co.jp/works/)
